# 開催期間の作業計画

開催期間(2026-11-02 12:00 〜 11-10 14:00 JST)に、どの順で何を作るかの計画です。毎朝の課題提案は、この表のその日の行から課題を選びます。1つのマスが1件の課題(半日以内)です。

## ゴール

締切の時点で、次の流れを dotmatrix40W の実機で見せられること。

1. 日本語で依頼する(例: 「左手だけで Photoshop を使いたい」)
2. Claude が今のキーマップをもとに新しいキーマップを作る
3. 変わったキーを図と日本語で説明する
4. `.vil` を書き出し、Vial で読み込むとキーボードに反映される

## 前提

- 人の関与は、課題の採用とマージの2つ。判断が要るもの(3日目の受け口など)は、Claude が選択肢を Issue に書き、採用のときに選んでもらう
- 例外として、実機が要る作業(Vial での読み込み確認、デモの録画)だけは人が行う。Claude が手順を Issue に書き、結果を一言で返してもらう
- 評価は [eval-cases.md](eval-cases.md) の14件(初期キーマップから始める 1〜10 と、普段使いの配列から始める M3、M6〜M8)。番号は評価例の番号
  - キーの位置で判定できるもの(1〜4、6〜8、M3、M6〜M8)は、`scripts/check_eval.py`(開催前に用意済み)で確かめる。このうち「〜を説明する」という項目(1、M3、M6 など)は、Claude の返答を読んで確かめる
  - 会話で判定するもの(5 説明だけで変えない、9 聞き返す、10 できないと説明する)は、Claude の返答を読んで確かめる
- 1日目の変換は [vil-format.md](vil-format.md) の調べに従う
