## 提案の前提(Built with Claude: Japan 2026)

- 開催: 2026-11-02 12:00 〜 11-10 14:00 JST。応募締切は 10-26 23:59 JST
- 2つの出発点のどちらかに沿うこと
  - ひとりの深い知見から: 自分が一番よく知っている仕事・技・日々の不便を形にする
  - 人々が手を携えて: 多くの人を阻んできた壁を取り払う。高齢化社会や人手不足など日本社会の課題
- 「Claude Code があれば初めての人でも動くものにできる」を示せるとよい
- チームは2名まで、日本在住者が対象
- 開催前(〜11/1)の提案は、仕組みと構想の準備に絞る。本体の実装は開催期間中に行う

## 決まった題材

- 自作キーボードのキー配置や動作を、日本語で話しかけるだけで設定できるツール。詳細は [project.md](project.md)

## アイデア

- 用途別のおすすめ配置(Photoshop、Illustrator、Blender、動画編集など)を会話の出発点として用意する
- 作ったキーマップを画像で書き出し、手元に置けるチートシートにする
- 片手デバイス(dotpad20 など)にも対応する
