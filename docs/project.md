# 構想: 話しかけて設定するキーボード

ハッカソンで作るものの構想です。実装は開催期間中(2026-11-02 〜 11-10)に行うため、ここに書いた内容は予定で、進めながら更新します。

## 解きたい課題

自作キーボードは、キー配置や動作を自分の手や仕事に合わせて変えられるのが魅力です。ところが実際に変えるには、次のような壁があります。

- ファームウェアのキーマップ(コード)を読み書きする必要がある
- ビルドしてキーボードに書き込む手順が分かりにくい
- 「やりたいこと」を「どのキーに何を割り当てるか」に落とし込むのが難しい

その結果、多くの人が買ったときの配置のまま使っています。

## 使う人

- デザイナーやイラストレーターなど、コードを書かない作り手
- 自作キーボードを持っているが、キーマップの変更をあきらめている人

## 体験の流れ

1. やりたいことを日本語で話しかける(例: 「左手だけで Photoshop のショートカットを使いたい」)
2. Claude が、今のキーマップをもとに新しいキーマップを作る
3. どのキーが何に変わったかを、図と日本語で説明する
4. 納得したら、キーボードへの書き込みまで手順を案内する

## 最初の範囲(ハッカソン期間中)

- 対象キーボードは dotmatrix40W(ワイヤレス 40%、4 行 × 12 列 + ロータリーエンコーダ)
- 日本語の依頼からキーマップを作り、変更点を説明するところまでを確実に動かす
- 書き込みは、dotmatrix40W が使っている RMK + Vial で案内する。詳細は [decisions/001-firmware.md](decisions/001-firmware.md)

具体的な課題の分割は、開催期間中に Claude が毎朝の提案(GitHub Issue)として出します。
